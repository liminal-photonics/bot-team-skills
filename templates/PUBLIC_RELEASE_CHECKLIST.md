# Public release checklist

- [ ] Author and committer on every commit use the public identity
- [ ] History searched for every never-public term (names, emails, handles, internal product details, customers, internal hosts)
- [ ] History searched for every secret by value (without printing it)
- [ ] Lockfiles, logs, fixtures, screenshots and package metadata checked
- [ ] Examples use generic or public data
- [ ] License and copyright holder correct
- [ ] No new CI workflows unless approved
- [ ] README speaks as the organization
- [ ] Approval for the public push/post recorded
